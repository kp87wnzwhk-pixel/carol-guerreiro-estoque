# Instalar no celular — Carol Guerreiro Estoque

## Publicar no GitHub Pages

1. Envie este projeto para o repositório **kp87wnzwhk-pixel/carol-guerreiro-estoque** (branch `main` ou `gh-pages`).
2. No GitHub: **Settings → Pages → Build and deployment**.
3. Em **Source**, escolha **Deploy from a branch**.
4. Selecione a branch (`main`) e a pasta `/ (root)`, depois **Save**.
5. Aguarde alguns minutos e abra:
   `https://kp87wnzwhk-pixel.github.io/carol-guerreiro-estoque/`

Use HTTPS (GitHub Pages já fornece). Sem HTTPS, a instalação como app pode falhar.

## iPhone (Safari)

1. Abra o site no **Safari**.
2. Toque em **Compartilhar** (ícone de quadrado com seta para cima).
3. Role e toque em **Adicionar à Tela de Início**.
4. Confirme o nome (**Carol Estoque**) e toque em **Adicionar**.
5. O ícone aparece na tela inicial; abra como app em tela cheia.

## Android (Chrome)

1. Abra o site no **Chrome**.
2. Se aparecer o banner **Instalar app**, toque nele.
3. Ou abra o menu **⋮** → **Instalar app** / **Adicionar à tela inicial**.
4. Confirme a instalação.
5. O atalho fica na tela inicial / gaveta de apps.

## Dicas

- Após atualizar o site, feche e reabra o app (ou limpe dados do site) para carregar a nova versão do cache (`cgi-estoque-v3`).
- Ícones PNG (192 / 512 / apple-touch) melhoram a instalação em iOS e Android.
